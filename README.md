A clean, responsive, and intuitive **Task Management & Todo Application** built with React, Vite, and Tailwind CSS. Designed to help users track personal productivity, prioritize tasks, and manage daily goals.

---

## ✨ Features
- **Task Creation & Editing**: Quickly add new tasks with priority and category tags.
- **Status Toggling**: Mark tasks as completed or pending with smooth state transitions.
- **Filter Views**: Switch seamlessly between All, Active, and Completed tasks.
- **Local Persistence**: Tasks are saved to browser LocalStorage so data persists across reloads.
- **Keyboard Shortcuts**: Press Enter to quickly submit new items.

---

## 🚀 Getting Started
```bash
npm install
npm run dev
```
